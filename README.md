## Quick start

Prerequisites:
- Node.js 18+ (or project Node version)
- pnpm (recommended) or npm

Install dependencies:

```bash
pnpm install
```

Run the dev server:

```bash
pnpm dev
```

Build for production:

```bash
pnpm build
pnpm start
```
